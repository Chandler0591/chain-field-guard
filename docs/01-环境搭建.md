# 环境搭建指南(WSL2)

> 目标环境:Windows 11 + Docker Desktop(WSL2 后端)+ WSL2 Ubuntu 24.04。代码、Go、Node、fabric-samples 全部位于 WSL 内,Windows 侧仅保留 Docker Desktop(容器引擎)与 IDE(编辑)。

## 0. 完成标准(做完本指南逐项勾选)

- [ ] WSL 内 `docker ps` 正常输出
- [ ] WSL 内 `git ls-remote https://github.com/... HEAD` 不卡死(直连或代理均可)
- [ ] `node -v` 输出 v22.x
- [ ] `go version` 输出 go1.22.x 或更高
- [ ] `~/fabric-samples` 克隆完成且 `docker images` 含 hyperledger/peer 等 2.5.11 镜像
- [ ] test-network 三步(`up createChannel` / `deployCC` / `down`)均无报错

---

## 1. 启动 Docker Desktop 并启用 WSL 集成

1. 启动 Docker Desktop
2. Settings → Resources → WSL Integration:勾选 **Ubuntu** 发行版,Apply & Restart
3. Settings → Resources → Proxies:配 HTTP/HTTPS 代理 `127.0.0.1:7897`(否则 Fabric 镜像拉不动)

在 WSL 内验证:

```bash
docker ps
docker version
```

`docker ps` 能输出表头即打通。

## 2. 打通 WSL 内代理(必要时)

WSL NAT 模式默认访问不到 Windows 的 localhost 代理。

> **先测后配**:在 WSL 内执行
> ```bash
> timeout 15 git ls-remote https://github.com/Chandler0591/chain-field-guard.git HEAD
> ```
> 能输出 commit 哈希则网络已通,本节可整体跳过。

**首选方案:mirrored 网络模式**(WSL 2.4+,本机为 2.7 已支持)

1. 创建/编辑 Windows 侧 `%UserProfile%\.wslconfig`:

```ini
[wsl2]
networkingMode=mirrored
memory=8GB
swap=4GB
```

2. 重启 WSL 使配置生效(会停掉所有 WSL 发行版与 Docker Desktop 容器):

```powershell
wsl --shutdown
```

3. 重新启动 Docker Desktop,然后在 WSL 内验证:

```bash
https_proxy=http://127.0.0.1:7897 git ls-remote https://github.com/Chandler0591/chain-field-guard.git HEAD
```

能看到 commit 哈希即成功。

**备选方案**(不改网络模式):Clash 开启"允许局域网连接",WSL 内:

```bash
export http_proxy=http://$(grep -m1 nameserver /etc/resolv.conf | cut -d" " -f2):7897
export https_proxy=http://$(grep -m1 nameserver /etc/resolv.conf | cut -d" " -f2):7897
```

**持久化**(mirrored 模式下):把以下两行追加到 `~/.bashrc`:

```bash
export http_proxy=http://127.0.0.1:7897
export https_proxy=http://127.0.0.1:7897
```

## 3. 安装工具链(WSL 内)

### Node 22(nvm)

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
source ~/.bashrc
nvm install 22
node --version   # 应为 v22.x
npm --version
```

### Go 1.22+

```bash
cd /tmp
wget https://go.dev/dl/go1.22.12.linux-amd64.tar.gz
sudo rm -rf /usr/local/go && sudo tar -C /usr/local -xzf go1.22.12.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
source ~/.bashrc
go version      # 应为 go1.22.x 或更高
```

> 若下载地址 404,用 https://go.dev/dl/ 上的最新 1.22.x 版本号替换。go 装好后建议配置 GOPROXY 加速依赖拉取:
> ```bash
> go env -w GOPROXY=https://goproxy.cn,direct
> ```

## 4. 克隆项目仓库与 git 凭证桥接

```bash
mkdir -p ~/codes
git clone https://github.com/Chandler0591/chain-field-guard.git ~/codes/chain-field-guard
cd ~/codes/chain-field-guard
```

**git 凭证桥接**(push 时免输账号密码,复用 Windows 的 Git Credential Manager):

```bash
git config --global credential.helper "/mnt/c/Program Files/Git/mingw64/bin/git-credential-manager.exe"
```

> 注意:`git config user.name/user.email` 需与 GitHub 账号匹配(Windows 侧已配 zhoufl / zfl@fastrise.net,WSL 内如为空请补配)。

## 5. 拉取 fabric-samples 与 Fabric 镜像

```bash
cd ~
git clone https://github.com/hyperledger/fabric-samples.git
cd fabric-samples
# fabric-samples 仓库最高 tag 为 v2.4.9(无 v2.5.x tag),2.5 LTS 直接用 main 分支
./install-fabric.sh --fabric-version 2.5.11 docker
```

脚本会拉取 peer / orderer / ca / tools / ccenv 等镜像(约 2GB,走 Docker Desktop 代理)。

验证:

```bash
docker images | grep hyperledger
```

应看到上述镜像且 TAG 为 `2.5.11`。

## 6. 验证 test-network 可跑通

```bash
cd ~/fabric-samples/test-network
./network.sh up createChannel
./network.sh deployCC -ccn basic -ccp ../asset-transfer-basic/chaincode-go -ccl go
./network.sh down
```

- 第 1 步:拉起 2 个 peer、1 个 orderer、1 个 CA,并创建 `mychannel`;成功后 `docker ps` 能看到 4 个容器
- 第 2 步:编译并部署 Go 链码 basic(会用到 Go 工具链)
- 第 3 步:全部清理

三步都无报错即环境就绪,可进入阶段 1(三组织改造)。

## 7. 常见报错速查

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| WSL 内 `git ls-remote` 卡死/超时 | 代理未打通 | 按第 2 节重配,`wsl --shutdown` 后重试 |
| `docker pull` 极慢或超时 | Docker Desktop 未配代理 | Settings → Resources → Proxies 配 `127.0.0.1:7897` |
| peer 容器反复重启 | 内存不足 | `.wslconfig` 里 `memory=8GB` 并 `wsl --shutdown` |
| `./network.sh` 报权限错误 | 脚本无执行位 | `chmod +x network.sh` |
| Go 链码部署编译失败 | Go 版本过低/依赖拉不动 | 确保 go1.22+,配 GOPROXY 后重试 |
| `git checkout v2.5.11` 报 pathspec 错误 | fabric-samples 无此 tag | 保持 main 分支即可,勿 checkout |
